# AGENTS.md

This repository contains only product data for an iPhone chatbot.

## Structure

- `products.csv` - iPhone product catalog with columns: id, name, image_url, description, available, price

## Notes

- No build/test scripts exist; this is a data-only repository
- Product availability is in the `available` column (0 = out of stock, 1+ = quantity available)
- Prices are in Indonesian Rupiah (IDR)
